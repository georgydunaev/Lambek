# Lambek Calculus Implementation in Coq

This repository contains a Coq implementation of Lambek calculus, a formal system in mathematical logic. The implementation includes definitions for variables, literals, words, and operations for negation and double negation. It also includes inductive definitions for `Plus` and `Minus` and tactics for pattern matching.

## File Structure

- `01.v`: Contains the main implementation of Lambek calculus in Coq.
- `examples/`: Directory containing example files demonstrating the use of Lambek calculus.
- `notes/`: Directory containing tutorial files providing step-by-step guides on using the implementation.
- `tickets/`: Directory containing various tickets related to the project.

- `01.v`: Contains the main implementation of Lambek calculus in Coq.

## Usage

To use this implementation, you need to have Coq installed on your system. You can then compile the `01.v` file using the Coq compiler to verify the proofs and definitions.
