# Documentation of Lambek Calculus, Substructural Logics, and Category Theory

## Introduction

This document aims to document the connections between Lambek calculus, substructural logics, and category theory. The implementation in Coq provides a formal foundation for understanding these connections.

## Lambek Calculus

Lambek calculus is a formal system in mathematical logic. It includes definitions for variables, literals, words, and operations for negation and double negation. The implementation in Coq defines these concepts and provides inductive definitions for Plus and Minus relations.

## Substructural Logics

Substructural logics are a family of logics that relax the structural rules of classical logic. Lambek calculus is a substructural logic that does not include the contraction and weakening rules. This makes it a non-commutative and non-associative logic.

## Category Theory

Category theory is a branch of mathematics that studies categories, which are collections of objects and morphisms between them. Lambek calculus can be interpreted in the category of finite ordinals, where the objects are finite ordinals and the morphisms are functions between them. This interpretation provides a categorical semantics for Lambek calculus.

## Connections

The connections between Lambek calculus, substructural logics, and category theory are deep and well-studied. Lambek calculus provides a formal foundation for substructural logics, and category theory provides a framework for interpreting these logics. The implementation in Coq allows for a formal and rigorous exploration of these connections.
